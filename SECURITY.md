# Security policy

*Versione italiana più sotto.*

## Reporting a vulnerability

Report security problems privately, with **Report a vulnerability** in the **Security** tab of this repository,
not in a public issue. For example:

- a file inside an evidence image that makes the module crash, hang or write outside the case folder;
- text taken from the evidence that becomes active content (a script, a link) in the HTML report;
- an output of Volatility 3 that makes the memory collector or the module misbehave.

Describe the problem and how to reproduce it, with the Autopsy version and the operating system. **Never attach
evidence from a real case**: if a sample is needed, build a small synthetic one.

Fixes are published in a new release: always use the latest one.

## Segnalare una vulnerabilità

Segnala i problemi di sicurezza in privato, con **Report a vulnerability** nella scheda **Security** di questo
repository, non in una issue pubblica. Per esempio:

- un file dentro un'immagine forense che fa bloccare il modulo, lo fa andare in errore o gli fa scrivere fuori dalla
  cartella del caso;
- un testo preso dalle prove che nel report HTML diventa contenuto attivo (uno script, un link);
- un output di Volatility 3 che manda in errore il raccoglitore della RAM o il modulo.

Descrivi il problema e come riprodurlo, con la versione di Autopsy e il sistema operativo. **Non allegare mai prove
di un caso reale**: se serve un esempio, costruiscine uno piccolo e sintetico.

Le correzioni escono con una nuova release: usa sempre l'ultima.
